# MyGAIAAgent

MyGAIAAgent is an AI agent built using Google's Flan-T5 Large model with Gradio. It allows users to ask questions and saves the answers automatically in GAIA JSONL format.

## Installation

1. Clone the repo:
```bash
git clone https://github.com/tchourse/MyGAIAAgent.git
cd MyGAIAAgent
````

2. Create and activate a virtual environment:

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the app:

```bash
python app.py
```

* Ask questions in the Gradio interface.
* Answers are saved in `gaia_submission.jsonl`.

## Files

* `app.py` — main application
* `requirements.txt` — dependencies
* `gaia_submission.jsonl` — saved outputs
